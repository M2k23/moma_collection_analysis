# moma_collection_analysis
Exploratory data analysis of a sample of the Museum of Modern Art collection using Python and Pandas.
Museum of Modern Art Collection Analysis

Project Overview

This project explores a sample of the Museum of Modern Art (MoMA) collection using Python and Pandas. It focuses on artwork creation dates, artist demographics, acquisition patterns, and artwork departments.

Dataset

The sample dataset contains 313 rows and 8 columns. It was obtained through the DataTweets tutorial on cleaning messy data with Pandas.

Data Cleaning

Standardized formatting in the Nationality and Gender columns.

Handled missing artist and medium values.

Identified and removed duplicate records.

Converted acquisition dates to datetime format.

Extracted artwork creation years from the original date values.

Analysis

Six basic analyses and two higher-level analyses examined:

Artwork creation periods and artist nationalities.

The time between artwork creation and acquisition.

Artist gender representation.

The oldest artwork and the most represented department.

Differences in artwork mediums across centuries.

Differences between creation and acquisition decades.

Key Findings

American artists accounted for 54.68% of the artwork records.

Male artists were associated with 77.59% of the records.

The Drawings and Prints department accounted for 55.52% of the records.

The most common creation decade was the 1920s, while the most common acquisition decade was the 1960s.

Limitations

The dataset represents a small sample rather than the entire MoMA collection. Missing information and the use of a single year to represent some creation-date ranges may affect the findings.
